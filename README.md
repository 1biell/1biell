## 🌟 Projetos Recentes

### 🍣 Sistema de Comanda Online
- Sistema de pedidos online para restaurantes, eliminando papel e confusões com pedidos.  
- Funcionalidades:
  - Garçom: Adicionar múltiplos itens, editar quantidades, enviar pedidos  
  - Cozinha: Visualizar pedidos, alterar status (pendente → em preparo → concluído)  
  - Histórico: Consultar pedidos concluídos, horários no fuso **America/Sao_Paulo**  
- Tech Stack: **React.js, Node.js, Express, PostgreSQL**
